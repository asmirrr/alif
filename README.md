# Alif

A modern Islamic companion app focused on prayer, reflection, and consistency.

Live Demo: https://getalif.vercel.app

## Features

* Dynamic prayer times based on location
* Qibla direction
* Daily reflections and reminders
* Prayer tracking and streaks
* Waitlist and feedback system
* Clean, modern interface

## Tech Stack

* Next.js 16
* TypeScript
* Tailwind CSS
* shadcn/ui
* Supabase
* Vercel

## Why Alif?

Many Islamic apps feel cluttered, outdated, or overloaded with features.

Alif focuses on simplicity, mindfulness, and daily consistency.

## Running Locally

```bash
npm install
npm run dev
```

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=your_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
```
